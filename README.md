# flumen-frontend-web

Web app for Flumen, an ephemeral file-sharing service with optional end-to-end encryption in the browser.

- Encryption format: [`docs/E2EE.md`](docs/E2EE.md)
- The app is built in later work; this repository currently holds project conventions.
